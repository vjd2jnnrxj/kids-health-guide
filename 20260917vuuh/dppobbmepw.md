# 预防脑卒中  不等中风来——九院神经外科中风防治团队“世界卒中日”义诊活动预告

> 更新时间：2026-09-17 (UTC+8)

**第18个世界卒中日**

**脑卒中**（俗称“中风”）是一种急性脑血管疾病，主要包括出血性卒中和缺血性卒中两大类型，**起病急、危害大**，具有高发病率、高致残率、高死亡率、高复发率以及高经济负担的特点，严重影响人们的健康生活。

平均每12秒，我国就有1人初发或复发脑中风，每21秒就有1人因脑中风离世。

虽然卒中来势汹汹、危害极大，但仍然是一种可防、可控的疾病。世界卒中组织最新指出，90%的卒中是可以避免发生的，因此，卒中的早期识别及预防非常重要。

**2023年世界卒中日主题为“卒中：重在预防”**，为了普及脑卒中防治知识，提高广大居民对脑卒中的认识，普及卒中诊疗知识、增强社会关注度、提高百姓卒中防治能力，**九院神经外科中风防治团队将举办“世界卒中日”专场义诊及科普宣教活动****。**

活动内容聚焦脑卒中疾病的预防、筛查、识别、诊治，帮助患者做到早发现、早救治、规范化治疗。现场备有卒中预防科普宣教资料及脑卒中预防小礼包，并由专业神经外科团队专家为患者答疑解惑。

**科普小贴士**

**如何预防脑卒中的发生**

1.  定期进行卒中危险因素的自我筛查，包括高血压、高血糖、高血脂、吸烟、饮酒、超重与肥胖、不健康生活习惯。

2.  控制好血压、血糖、血脂。

3.  戒烟、控制体重、健康饮食、科学运动。

4.  应当有专业医师进行评估、筛查、干预和随访。

**九院神经外科脑中风专病门诊介绍**

**九院神经外科（北部）开设有脑中风专病门诊**，针对危险人群进行危险因素分析，团队共10位成员，其中高级职称专家3位。
