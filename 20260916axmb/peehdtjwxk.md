# 警惕！北海一男子手指被螃蟹刺伤，引发严重感染，坏死被截除

> 更新时间：2026-09-16 (UTC+8)

处理海鲜被扎到时常发生，很多人都不太会在意，但小伤口也有可能带来大麻烦，近日，市人民医院就接诊了一位手指被螃蟹扎伤后感染，最后不得不截掉的患者。

⇊⇊

**PART.****0****1****被螃蟹被扎伤  男子手指肿痛发黑**

据患者李叔（化名）介绍，5月21日，他在家准备晚饭，在处理螃蟹时左手食指不慎被扎伤一个小口子，由于伤口不严重，李叔并未在意，当晚也未感到任何不适，直到次日早上五点钟，李叔伤口开始肿胀疼痛，他怀疑可能是感染了破伤风，随即前往附近医院就诊，医生为其注射了破伤风针并开具了止疼药，但是疼痛并未缓解。当天下午五点，李叔转至我院急诊科进行处理，在进行麻药封闭后，当晚疼痛有所缓解。然而次日针口出现血水渗出的情况，当晚9点多，李叔不得不再次来到前往医院就诊。

**PART.****0****2**
**小小伤口竟致截肢**
此时，李叔手指已经严重肿胀，发黑流脓，经过医生研判，急需外科介入治疗，于是李叔被收治到骨科。5月23日，由银滩院区骨科主任朱金荣、副主任覃育接、曹桂青医生共同为李叔手术，术中清除掉坏死的组织，使用药物控制感染，同时通过负压引流的方式，促进肉芽组织生长，力求保住李叔的手指头。

但是李叔手指感染实在过于严重，感染已经累及整个手掌和手臂，为防止感染进一步加重，危害生命，5月30日，李叔不得不进行第二次手术，将食指截肢。

**PART.****0****3****“海洋无声杀手”作祟：创伤弧菌感染**

**为何小伤酿成大祸？**

医生诊断李叔感染了**海洋创伤弧菌**，这种栖息于海洋的“无声杀手”，常寄生在螃蟹、贝类、海鱼等海鲜中，可通过伤口或生食感染。

一旦感染，病情凶险，会引发严重败血症及肢体坏死，进展极快，死亡率高达50%-70%，多数患者可能在48小时内死于脓毒性休克及多器官衰竭。

被海鲜扎伤的报道屡见不鲜

**医生提醒：**

创伤弧菌感染是高度急重症，病情发展以小时计算。初期可能仅感伤口刺痛麻木，但若快速出现发热、寒战、皮肤剧烈肿胀甚至含血水的大水泡，务必火速就医！

**PART.****0****4**
**安全享用海鲜，谨记防护要点**
创伤弧菌虽然凶险，但也不用避海鲜而不及。
一般来说，免疫功能正常的健康人群，是不容易经口感染的。

普通人群需要警惕的是经伤口感染。
而那些平时喜欢生食海鲜、长期接触海水的、有肝病和免疫力低下的人群，则需要特别注意——

1. 肝病患者、免疫功能低下者、酗酒者，切忌生食海鲜。

2. 下海游玩最好不要赤足，不要光脚在贝类多的沙滩漫步，伤口部位应避免接触海水或海产品。

3. 宰杀或清洗海鲜、淡水鱼的过程中，最好佩戴较厚的橡胶手套，可有效防止刺伤。

4. 切勿生食或半生食海鲜，尽量将海产品煮熟透后食用。
